# Skills 技能

在侧边栏打开 **Skills 技能**。本机统一技能库存放技能副本，“已安装”中的工具开关决定该技能是否部署到当前工作环境。

## 添加技能

- **在发现里浏览**：输入 `owner/repo` 格式的公开 GitHub 仓库，点击“读取仓库”。内置 Anthropic 与 OpenAI 仓库入口；选择“安装到”的工具后，点击技能行的“安装”。下载固定到发现时的仓库版本。
- **从 ZIP 安装**：选择包含 `SKILL.md` 的 ZIP，支持同一归档内多个技能，脚本和其他资源随技能复制。技能进入技能库后，在“已安装”中开启需要的工具。同名技能跳过，不覆盖。
- **导入本机已有**：扫描本机 Codex、Claude Code、Gemini CLI、OpenCode 以及共享 `.agents/skills` 目录。导入只复制，不移动或删除原文件。

可以按名称、目录或描述搜索技能。GitHub 访问失败或限流时会显示实际错误，可改用 ZIP 安装。

## 本机与远程工作环境

本机工具目录遵循 `CODEX_HOME`、`CLAUDE_CONFIG_DIR`、`GEMINI_CLI_HOME`、`XDG_CONFIG_HOME`，默认使用各工具的用户技能目录。

远程环境通过 SSH 写入 Edge Switch 启动工具实际使用的独立配置目录，并区分 API 配置与官方账号配置。切换工作环境或账号模式后，工具开关反映新目标目录的状态，需要时重新开启。技能库在本机复用，启用状态按目标目录判断。

关闭开关会移除由 Edge Switch 部署且内容未变的副本。工具原有目录、外部修改后的副本均保留，并显示处理原因。请先备份并自行处理同名目录冲突。

ZIP 和单个技能内容限制为 32 MiB；拒绝目录穿越和符号链接。导入和部署技能不会执行其中的脚本。当前支持 Codex、Claude Code、Gemini CLI、OpenCode；不为尚未确认技能目录规范的工具提供开关。

## 授权中心的本机登录

本机环境支持 ChatGPT 与 DeepSeek 浏览器授权。ChatGPT 授权会写入本机 Codex `auth.json`，原凭据先备份，并在当前环境加密记录；设备码授权打开本机 Codex 终端。Claude Code、Gemini CLI、OpenCode 的账号入口打开对应的本机官方登录终端。

“检测已有登录”读取本机 Codex 凭据；打开终端本身不代表授权完成。授权不会自动替换当前选择的 API 供应商。浏览器授权需要用户在官方网页上完成交互。
