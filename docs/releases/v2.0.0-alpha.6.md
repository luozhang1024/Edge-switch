# Edge Switch v2.0.0-alpha.6

面向 Windows 10/11 x64 的 Tauri 桌面预发布版。AI 工具运行在通过 SSH 连接的 Linux 板卡上。

## 新增与调整

- 设置 → 通用新增当前用户开机自启、关闭窗口时最小化到托盘开关。
- 新增中文 / English 界面切换，立即生效并持久保存。
- 移除首页工作环境选择器点击时的圆弧边框。
- 创建、编辑具体环境时配置 SSH、代理和 AI 工具；列表支持悬停操作、启用状态和拖动排序。
- 模型服务默认提供各 CLI 官方入口，Harness 提供待配置的 DeepSeek API；保留已有配置。
- 任务进度、结果和错误自动弹窗，日志位于设置。
- 便携包新增启动诊断脚本和经签名验证的微软 WebView2 引导安装程序。主程序启动失败显示错误，并记录 `%LOCALAPPDATA%\EdgeSSHAI\startup.log`。
- 更新中英文 README 与当前界面截图，清理未被引用的历史截图。

## 下载与升级

推荐下载 `Edge Switch_2.0.0-alpha.6_x64-setup.exe`。便携版请完整解压 `EdgeSwitch-2.0.0-alpha.6-Windows-x64.zip`，首次运行 `Launch-EdgeSwitch.cmd`；WebView2 未安装时需要联网下载运行时。离线电脑请预先安装官方离线 WebView2 运行时。

升级前从托盘退出旧实例。便携版启用自启后应保持路径不变；移动后重新切换自启开关。Windows 7/8、32 位系统和 ARM 原生构建不在本次支持范围内。

## 验证范围

发布流程运行前端测试、浏览器交互验证、Rust 检查与测试，并构建、验证 Windows 桌面。浏览器测试使用模拟板卡，未完成本版本真实板卡、账号授权及所有 Windows 环境验收。

同事电脑上的“无反应 / 一闪而过”尚未获得具体错误日志；此版补齐依赖检查和错误诊断，不能将所有此类启动故障归因于 WebView2。请提供便携启动日志或系统提示继续定位。

English: This prerelease adds per-user startup, configurable close-to-tray behavior, persistent Chinese/English UI, and portable startup diagnostics with Microsoft's WebView2 bootstrapper. Extract the full ZIP and run `Launch-EdgeSwitch.cmd`. Requires Windows 10/11 x64. Real-board and broad Windows compatibility acceptance are not complete.
