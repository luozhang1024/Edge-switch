# Edge Switch v1.0.3

修复 v1.0.2 下载失败后仅保留完整分块、遇到单块失败立即结束的问题。

- 保留分块内已收到的数据，下一次从该字节继续请求；仅在 `Content-Range` 与请求范围、总大小精确一致时接纳字节。
- 单块自动重试最多 6 次；启用电脑代理时，失败后交替尝试代理与电脑直连。仅用于微软公开下载，不改变 API / Codex 的认证与代理选择。
- 并发从 6 降至 3，减少弱网络下的竞争；单次请求 90 秒，下载阶段仍有 10 分钟上限。失败或超时结束时也保存有效的部分响应。
- 进度统计已保留到分块中的字节，正在接收的字节稍后计入，避免重试清零导致显示倒退。
- AI 工具页新增“导入服务端”。可用浏览器、下载工具或其他电脑下载微软官方包，再导入本机。打开 VS Code 时会读取对应版本官方 SHA-256 并检查大小，通过后才上传；导入不等于已验证，读取官方校验信息仍需要网络。
- 本机缓存还可直接识别 `vscode-server-linux-arm64.tar.gz` 或 `vscode-server-linux-x64.tar.gz`，与官方校验一致后自动接入。

## 代理行为

“打开 VS Code”不会启动 FlClash，不修改系统代理。电脑下载按环境的电脑代理开关和端口执行；启用 Codex 代理时，会按需建立 SSH 反向隧道给板卡使用。电脑 HTTP 代理、板卡隧道与局域网 SSH 连接是不同路径。

## 手动下载

当前日志对应 VS Code commit `6bab64e2d12b04d04c0d99c27ff166023efd1dda`、ARM64：

https://update.code.visualstudio.com/commit:6bab64e2d12b04d04c0d99c27ff166023efd1dda/server-linux-arm64/stable

下载完成后在 AI 工具页点击“导入服务端”，选择 `.tar.gz`，再点击“打开 VS Code”。电脑 VS Code 更新后需要对应的新包，旧包不会通过新版本的官方校验。
