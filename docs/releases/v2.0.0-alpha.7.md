# v2.0.0-alpha.7

此版本使用 SemVer 预发布版本号，GitHub Release 标签应为 `v2.0.0-alpha.7` 并勾选 **Set as a pre-release**。本次本地构建不自动创建标签或发布 Release。

- 模型服务：操作按钮常显；本机 Codex 当前供应商可直接编辑、复制到列表、连接测试和删除，修改前备份配置，密钥不传给界面。补齐默认 DeepSeek API 的配置、复制、测试引导和删除入口。
- 用量统计：新增全部时间和按年查看的每日 Token 热力图，统计覆盖所有已读取记录，仍支持工具、供应商、模型筛选。
- 授权中心：通过 Windows 注册的默认浏览器打开官方授权地址，不再使用 Explorer 解析 URL；显示等待状态，支持复制链接、重新打开、取消授权。ChatGPT、DeepSeek Harness 提供三点菜单退出账号，保留 API 配置与会话。
- 工具安装：新增 Kimi Code、Grok CLI、Qwen Code、GitHub Copilot CLI 的安装、升级、卸载与终端启动。Grok CLI 是社区项目，非 xAI 官方产品。新增工具的供应商配置使用各工具自身流程；仅现有五种工具提供模型服务适配。
- 网络：环境编辑不再显示代理连接页签；设置 → 高级 → 网络配置本机 FlClash HTTP / Mixed 代理，应用的授权、API、Skills、版本查询与下载请求共用代理，SSH 环境经反向隧道访问。代理密码在本机加密保存，修改时断开旧隧道，已运行终端需重开。

## 发布资产

构建输出保存在 `dist/tauri/v2.0.0-alpha.7/`，与其他版本隔离：

- `Edge Switch_2.0.0-alpha.7_x64-setup.exe`（上传 GitHub 时文件名中的空格由 GitHub 规范化为点）
- `EdgeSwitch-2.0.0-alpha.7-Windows-x64.zip`
- `EdgeSwitch.exe`
- `EdgeSwitch-2.0.0-alpha.7-source.zip`
- `SHA256SUMS.txt`

版本检查会校验 package.json、npm 锁文件、Cargo 元数据与 Tauri 配置一致。构建要求源码已提交，源码 ZIP 与构建提交一致；若版本标签已指向其他提交，会拒绝用同一版本打包。

## 验证范围

自动化验证覆盖供应商操作、用量聚合、授权入口和取消、退出账号保留 API 凭据、网络配置与实际代理请求、工具目录管理及桌面 WebView2 交互。真实账号的最终网页授权需要用户本人完成；新增 CLI 的在线安装受其上游网络、系统与处理器支持影响。尚未完成真实 Linux 板卡上的端到端验收。
