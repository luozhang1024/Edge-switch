# Edge Switch v1.0.0

Edge Switch 首次正式发布：在 Windows 上管理 Linux 板卡的 SSH 工作环境、AI 工具、代理线路及模型服务。

## 主要功能

- 工作环境卡片管理，支持设备连接测试与首次 SSH 密钥授权。
- 独立 Node.js 运行环境、Codex / DeepSeek Harness 安装与版本选择。
- 多 API 服务切换及内置 OpenAI Official 账号入口，支持设备码登录和导入本人 auth.json。
- 连通性测试与最小推理验证；推理前提示可能消耗额度。
- VS Code Remote SSH / Codex 扩展接入，Harness 网页转发与后台运行。
- Codex / Harness 独立代理设置、隧道自动重连和系统托盘。
- 程序统一命名为 Edge Switch，版本采用 SemVer；提供中英文 README。
- AGPL-3.0-only 许可，安装包、便携包附带 LICENSE，并提供对应源码附件。

## 环境与升级

桌面端：Windows x64 + OpenSSH；远程编辑另需 VS Code。

板卡：Linux ARM64 / x86_64、glibc ≥ 2.28、Python ≥ 3.8、SSH 服务与可写用户目录。已实机验证 LPB3568 / ARM64 / glibc 2.31，其他环境仍需满足上游依赖。

升级前请从侧栏或托盘选择“退出程序”。保留旧应用标识及 `%LOCALAPPDATA%\EdgeSSHAI` 配置目录，升级后可继续使用原工作环境；安装目录沿用旧位置。程序和新快捷方式显示为 Edge Switch，旧快捷方式如仍存在可手动取消固定或删除。

## 已知边界

- 程序界面当前为中文，英文版为文档语言切换。
- 官方账号与 API 权限、额度及网络可用性由各服务方决定；未代用户验证真实账号推理。
- Harness 的模型配置仍在其网页内管理。
- 共用 Linux 账号是配置分离，不是用户权限隔离。
- 依赖电脑代理的任务需要电脑、代理和工作台在线；后台运行不包含板卡重启自启。
- Windows 构建未进行代码签名，系统可能显示未知发布者提示。
