# Edge Switch v1.0.1

修复多台电脑共用 Linux 板卡时已有工具漏检，并补充首次 VS Code 连接配置与诊断。修复侧栏 Edge Switch 名称截断。

## 修复内容

- 工具检测不再仅检查当前电脑的环境目录：扫描同一 Linux 账号下的工作台安装和 PATH 中的 Codex / Harness，显示版本及来源；失效的安装标记不再算作已安装。
- 新环境可在 AI 工具页点击“使用已有工具”，验证版本后复用已有程序和受管 Node.js，无需重复下载。首次启动需要的工具也会尝试接入已有安装。
- 仅复用程序文件；不复制另一环境的 API 密钥、官方账号、工程配置或 Harness 进程。复用的安装来源被删除后，需要重新安装或接入其他可用安装。
- VS Code 明确远程平台为 Linux，使用专用私钥、保活和连接超时；关闭本机服务和 Exec Server 模式，并展示登录终端，减少首次连接时隐藏提示和启动模式差异。
- 打开前，使用 VS Code 实际采用的专用 SSH 配置进行登录预检；工作台显示检查、安装扩展和打开请求的阶段进度。
- 模型服务页新增“连接诊断”，从最近的 Remote - SSH 日志中总结连接阶段或错误，不显示原始令牌和服务端输出。无日志时提供下一步操作。
- 缩小品牌区 Logo、字号和间距，确保侧栏显示完整名称。

## 验证与限制

- 已用全新临时环境模拟同事电脑，实机验证已有工具发现、版本校验复用、配置隔离和生成的专用 SSH 配置登录。
- 未取得同事电脑的真实 Remote - SSH 错误日志，因此不能断言其 VS Code 连接卡住的具体原因已确定。若升级后仍卡住，请点击“连接诊断”，提供诊断结果。
- “已发送打开请求”不等于 VS Code Server 已建立连接。模型凭据仍需每个环境独立设置。
- 程序界面当前为中文；中英文 README 可通过首页顶部链接切换。
