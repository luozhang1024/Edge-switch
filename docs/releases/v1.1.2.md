# Edge Switch v1.1.2

修复工作台已准备服务端，Remote SSH 仍提示下载的问题。实际日志显示 Remote SSH 会在 `serverInstallPath` 后追加 `.vscode-server`；此前工作台误把最终服务目录当作基目录，导致检查路径与启动路径不一致。

- 将实际服务目录统一为当前环境下的 `.vscode-server`，`serverInstallPath` 指向其父目录。
- 自动从此前 `vscode-server` 目录复用匹配的服务端程序及 Codex 扩展，不重复联网下载，不复制登录凭据、服务进程状态或安装锁，不删除旧目录。
- 服务端准备、扩展安装和登录启动器均使用同一个实际目录。
- 调整路径回归检查，验证 Remote SSH 追加子目录后与准备目录一致。

仍保留旧目录作为兼容来源，迁移复制会占用额外磁盘；不自动关闭旧窗口、终止服务或删除旧安装。
