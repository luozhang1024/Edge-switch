# Edge Switch v1.1.1

修复服务端准备成功后仍提示“请先在远程 VS Code 安装 Codex 扩展”的问题。原流程调用 Windows VS Code CLI 安装远程扩展，未验证其是否实际出现在当前环境的板卡扩展目录；共享目录已有扩展也没有被当前环境接入。

- 直接通过 SSH 在板卡执行当前版本 VS Code Server 的扩展管理 CLI，并显式指定独立扩展与数据目录。
- 优先从板卡共享目录或其他工作台环境复用已有 Codex 扩展程序包；只复制扩展程序目录，不复制登录凭据、全局用户状态或任务数据。
- 验证扩展 manifest 中的 publisher / name、本机架构 CLI、VS Code Server 的扩展注册列表，以及 CLI `--version`。安装命令退出码成功但文件或注册缺失时明确失败。
- 没有可复用扩展时由板卡的 Server CLI 安装，再执行相同检查。安装仍需要板卡能访问扩展市场，使用当前环境代理。
- 扩展准备采用当前环境独立锁，不影响其他环境正在运行的服务。
- 先准备扩展并同步登录启动器，再打开远程窗口，减少首次激活时读到旧配置的问题。
