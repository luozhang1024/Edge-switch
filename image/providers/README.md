# Provider icons

Source: https://github.com/lobehub/lobe-icons/tree/ea434b96e75813517b377825e01c0df61dee8836/packages/static-svg/icons

License: MIT, copyright LobeHub. Original SVG files are bundled locally; no runtime CDN requests. Brand marks remain the property of their owners.

Brand catalog: https://lobehub.com/zh/icons

The Codex tool uses `codex.svg`; ChatGPT account authorization uses the OpenAI mark (`openai.svg`). Claude Code, Gemini CLI, DeepSeek Harness and OpenCode use their corresponding LobeHub marks. API providers use their own brand marks independently of the selected CLI tool. Monochrome marks adapt to the dark theme; colored brand marks retain their original colors.

`openai-official.svg` is a legacy local green (#00a67e) variant of `openai.svg`.

Kimi (`kimi-color.svg`), Grok (`grok.svg`), Qwen (`qwen-color.svg`) and GitHub Copilot (`githubcopilot.svg`) were retrieved from the same LobeHub static SVG catalog on 2026-11-13 under its MIT license. These assets are bundled locally and reused across tool installation, model services, Skills and prompt groups.
